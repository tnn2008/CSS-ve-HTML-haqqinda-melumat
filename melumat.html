⬅ Girişə Qayıt

HTML nədir?

HTML veb-səhifələrin strukturunu müəyyənləşdirən etiket dilidir.

  • Mətnləri, şəkilləri və keçidləri təşkil edir.
  • Semantik etiketlərlə işləyir.

CSS nədir?

CSS veb-səhifələrin vizual tərtibatını və rənglərini tənzimləyir.

  • Dizaynı məzmundan ayırır.
  • Flexbox və Grid strukturları ilə səhifələri formalaşdırır.

Praktik Layihələr

Yalnız HTML və CSS ilə interaktiv veb-saytlar yarada bilərsiniz.

  • Giriş formaları.
  • Pure CSS Slayderlər.
